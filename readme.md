# Skill — Gerador DANFSe

Skill para integrar o serviço HTTP da Receita Federal que gera o DANFSe em PDF
a partir do XML de uma NFS-e.

## Arquivos

- `skill.pt-BR.md` — instruções em português do Brasil
- `skill.en.md` — instruções em inglês

## Repositório oficial

https://github.com/ReceitaFederal/calculadora-rtc-gerador-danfse

Este skill é mantido no ecossistema https://github.com/GambiarraFinance.

## Porta padrão

`8080`.
